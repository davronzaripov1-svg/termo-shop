# TermoStick - User Flow и сценарии использования

## Обзор

Документ описывает основные пользовательские сценарии и навигацию в приложении TermoStick.

---

## Типы пользователей

### 1. Гость (Guest)
- Просмотр каталога
- Просмотр технологий
- Расчет стоимости
- Ограниченный доступ

### 2. Частный клиент (Customer)
- Все возможности гостя
- Создание заказов
- История заказов
- Личный кабинет

### 3. Бизнес клиент (Business)
- Все возможности клиента
- Оптовые цены
- Приоритетная поддержка
- Отсрочка платежа (опционально)

### 4. Администратор (Admin)
- Управление заказами
- Управление продукцией
- Управление пользователями
- Аналитика

---

```
┌─────────────────┐
│ Конструктор     │
└────────┬────────┘
         │
         └─→ Клик "Загрузить файл"
                │
      ┌─────────▼─────────┐

      │ - PNG, PDF, SVG   │

      │ - Max 50MB        │
      └─────────┬─────────┘

      ┌─────────▼─────────┐
      │ Загрузка на сервер│
      │ [Progress bar]    │
      └─────────┬─────────┘
                │
      ┌─────────▼─────────┐
      │ Автоматическая    │
      │ проверка:         │
      │ - DPI (min 300)   │
      │ - Размер          │
      │ - Цветовой режим  │
      │ - Формат          │
      └─────────┬─────────┘
                │
                ├─→ ✅ Файл валиден
                │      │
                │      └─→ Превью + Продолжить
                │
                └─→ ❌ Ошибки валидации
                       │
                       ├─→ DPI < 300 → Предупреждение
                       │   "Низкое качество, продолжить?"
                       │
                       ├─→ Неверный формат → Ошибка
                       │   "Загрузите PNG, PDF или SVG"
                       │
                       └─→ Слишком большой → Ошибка
                           "Максимум 50MB"
```

## Уведомления

### Push уведомления
1. **Заказ создан** - "Ваш заказ #TS-2025-001234 принят в работу"
2. **Оплата получена** - "Оплата заказа #TS-2025-001234 подтверждена"
3. **В производстве** - "Заказ #TS-2025-001234 в производстве"
4. **Готов к выдаче** - "Заказ #TS-2025-001234 готов! Можете забрать"
5. **Завершен** - "Спасибо за заказ! Оставьте отзыв"

### Telegram уведомления
- Дублирование всех push уведомлений
- Возможность ответить на уведомление
- Быстрые команды (/orders, /status)

### Email уведомления
- Подтверждение регистрации
- Чек заказа
- Изменение статуса
- Промо и акции (опционально)

- **Мобильное меню** - Hamburger menu
- **Bottom navigation** - Главная, Каталог, Корзина, Профиль

- Упрощенные формы
- Автозаполнение
- Камера для загрузки фото
- Геолокация для адреса доставки

## Ключевые метрики UX

### Время выполнения задач
- Регистрация: < 2 минуты
- Создание заказа: < 5 минут
- Поиск продукта: < 30 секунд
- Оплата: < 2 минуты

### Конверсия
- Посетитель → Регистрация: 15%
- Просмотр → Добавление в корзину: 25%
- Корзина → Оформление: 60%
- Оформление → Оплата: 80%

### Удержание
- Повторные заказы: 40% в течение 3 месяцев
- Возврат на сайт: 50% в течение недели
- Активные пользователи: 30% ежемесячно

## A/B тестирование

### Приоритетные гипотезы
1. Расположение кнопки "Быстрый заказ"
2. Цветовая схема CTA кнопок
3. Формат отображения цен
4. Упрощенная vs детальная форма регистрации
5. Одностраничный vs многошаговый checkout

---

## Accessibility (Доступность)

### WCAG 2.1 Level AA
- Контрастность текста: минимум 4.5:1
- Keyboard navigation
- Screen reader поддержка
- Alt текст для изображений
- ARIA labels

### Поддержка языков
- Русский (основной)
- Узбекский
- Английский

### Темная тема
- Автоматическое переключение по системным настройкам
- Ручное переключение
- Сохранение предпочтений
